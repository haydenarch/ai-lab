# ai-lab

Khun's AI experiment lab — learning in public, one shipped automation at a time.

Career goal: **Build AI apps and agents** (Oct 2026 → Mar 2027).

## The five rules

1. **Ship every phase.** A small working thing beats a finished course with nothing to show.
2. **Free first.** Local models, free tiers, open-source repos before any paid spend.
3. **One framework deep.** Learn LangGraph properly; sample others only to compare.
4. **Automate your real life.** Every project should save time, teach a class, or help the shop — no toy-only projects.
5. **Write it down.** A short README and learning note per project. That writing becomes the portfolio.

## Layout

- `experiments/` — one folder per experiment: `NNN-short-name/` with a `README.md` (what / why / what happened) + code.
- `notes/` — learning notes in your own words (optional but powerful).
- `14-day-checklist.md` — the first 14 days, tick as you go.

## Experiment log habit

Every experiment gets a folder + README answering five questions: What did I try? What happened? What broke? What did I learn? What's next? See `experiments/000-template.md`.
